# Findings

A log of every fuzzing campaign and every bug found by fuzzing, sanitizers, Miri or the conformance
harness. One row per run of a target, newest first. `runs` is the number of executions (or the
duration for time-boxed runs); `result` is `clean`, or a short description of the failure with the
input saved under the target's corpus or artifacts directory. A finding stays in the table after it
is fixed: `notes` names the fix and the regression test that now covers it.
