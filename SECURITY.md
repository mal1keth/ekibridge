# Security policy

ekibridge is a demonstration and learning project and is not intended for production use. No
release is tagged.

If you believe you have found a security issue, please report it privately through a GitHub
security advisory on this repository (Security tab, "Report a vulnerability") rather than in a
public issue. I read and answer reports on a best-effort basis. There is no bug bounty.

The [threat model](docs/threat-model.md) says what the libraries protect and what they leave out.
